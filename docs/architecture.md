# V0 架构

```text
Vue 3 SPA
  └─ HTTP API
       └─ FastAPI
            ├─ API/数据校验
            ├─ 后续：确定性问题工作流与持久化
            └─ Agent boundary
                 ├─ Hello-Agents 单 Agent
                 ├─ Pydantic/JSON Schema 结构化输出
                 └─ 最小受控 ToolRegistry
```

## 当前已经实现

- 前端起始页和运行状态检查。
- 后端 `/health`、`/api/runtime`。
- Agent 配置、问题分析 Schema、工具统一返回协议。
- 严格文字输入契约，以及无工具、无共享历史的单 Agent 基础对话边界。
- 冻结的 `IssueAnalysis` JSON Schema 与严格结构化输出解析边界。
- 无工具、无共享历史的 `IssueAnalyzer`，结构化分析协议支持六个主类别和五级风险。
- 信息不足和高风险的确定性跨字段门禁：缺失信息必须显式列出并说明不确定性；高风险和紧急风险
  必须给出避险提示、标记人工复核并路由人工复核。
- 覆盖 20 条固定案例及正常、空输入、非法 JSON、超时、模型错误的离线 Fake LLM 协议测试。
- 独立的 `propose_issue_record` 工具契约与最小注册表；当前只生成明确未保存、未派单的待确认提案，
  尚未接入 Agent、API 或页面。
- 自动测试和前端生产构建。

## 当前明确未实现

- 对话 API、前端对话入口和真实模型调用；真实模型的分类与风险准确率尚未验收。
- 正式问题记录、用户确认、持久化、派单、整改、复查和关闭。
- 图片二进制上传与多模态模型调用。
- 知识库、RAG、OCR、通知和外部企业系统。

## 目标调用链

```text
用户文字/照片
  → 输入边界校验
  → 单 Agent 生成 IssueAnalysis
  → 普通咨询：直接回答
  → 需跟进：生成问题记录提案
  → 用户确认
  → 确定性工作流落库
  → 人工整改与复查
```

## 状态所有权

- 浏览器只展示服务端状态。
- FastAPI 工作流服务是问题记录状态的唯一事实来源。
- Agent 只能返回分析和动作提案，不能直接写数据库。
- 知识材料是依据来源，不能替代专业人员结论。

## 安全设计

- 高风险判断始终要求人工复核。
- 信息不足时显式返回缺失字段和不确定性，禁止猜测地点、人员、现场状态或责任。
- 立即行动只用于降低暴露和阻止危险扩大，不构成最终工程方案或无资质操作授权。
- 图片识别结果区分事实观察和推测。
- 不将隐藏思维链写入日志，只记录动作理由摘要和工具结果。
- 所有会产生副作用的动作由代码判断权限和确认状态。
