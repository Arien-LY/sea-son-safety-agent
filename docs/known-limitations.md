# 已知限制与上线前门禁

## 不能对外宣称已经完成

- 真实文字模型的20案例准确率、高风险召回、Token、费用与开放问题质量尚未完成专业标注验收。
- 视觉只做过获授权的合成图连通性冒烟；没有真实工地图片识别准确率结论。
- 当前页面的actor ID是演示身份，不是登录、项目成员关系、执业资格或审批授权。
- JSON Store与图片锁只保证当前单机/单进程设计，不提供多进程事务、生产数据库、备份或灾难恢复。
- 未接企业工单、通知、SSO、审计平台、对象存储、病毒扫描、DLP或正式数据保留/删除策略。
- Phase 0要求的第二台物理Windows电脑复现必须由另一位队员实际执行并签字。

## 模型与Agent限制

- 普通聊天可长回答，但不做业务分析或工单建议；专业咨询最多6轮，未保存会话在刷新/重启后丢失。
- 停止等待只取消本地接收，不保证供应商停止计算或计费；当前零自动重试。
- 模型可能输出不完整、错误或不规范Markdown；结构化路径会失败关闭，自由聊天仍需用户判断。
- 系统不展示隐藏思维链；页面中的“步骤/工具”只来自服务端事件，不代表模型内部推理。
- 仅一个业务Agent边界；没有多智能体协作、自治后台任务或自动业务写权限。
- 文字服务商支持 DeepSeek 官方与腾讯云 Token Plan 两个白名单端点；Token Plan 的可用模型以控制台
  套餐为准，适配器尚未做付费真实文字冒烟，也不能证明模型准确率或费用符合预期。

## 安全、知识和图片限制

- AI建议不能代替安全员、质量人员或其他专业人员的工程判断；高风险必须人工复核。
- 首批知识库只有2份中国内地公开法规、8条本地释义；关键词检索不是开放域法律检索。
- 引用只证明目录来源，不自动证明项目、地区、时间或具体事实适用；过期/未知范围会降级。
- EXIF清理不能消除图片像素中的人脸、工牌、位置或隐私；上传前必须人工授权和打码。
- 只支持单张JPEG/PNG、5MiB、4096边长；不支持多图推理、视频、OCR或自动人脸打码。
- 图片分析仍只接 DeepSeek 官方视觉模型；腾讯云 Token Plan 的多模态模型、图片参数和视觉契约需要单独
  适配与真实图片验收，本轮没有伪装为已支持。

## 前端与运行限制

- 聊天历史仅存在当前页面和单进程内存；正式工单才写入本地Store。
- 本地搜索词可能进入URL/访问日志，不应填写敏感资料。
- Markdown无语法高亮或复制按钮；页面只逐段显示已通过Schema校验的答案，不直通供应商原始token，
  因而不会缩短模型首字等待。远程图片被阻止，链接只允许HTTP(S)/mailto。
- 目标为Windows本机受控演示，不应直接监听公网；默认开发服务器不具备生产TLS、WAF或限流。
- npm审计仍报告基线工具链中的`postcss`/`nanoid`告警，需在单独依赖升级任务中评估兼容修复。

## 发布门禁

上线前至少需要：真实身份与项目权限、生产数据库/备份、跨进程并发、隐私影响评估、授权数据集、
专业准确率与红队测试、真实费用/延迟预算、依赖漏洞处置、两台物理电脑复现、运维监控和应急回滚。
