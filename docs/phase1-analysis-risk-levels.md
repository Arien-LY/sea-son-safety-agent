# Phase 1 五级风险分析协议

## 任务边界

目标：让结构化分析协议支持 `undetermined/low/medium/high/emergency` 五级风险，冻结每一级的
严重性与紧迫度语义，并与类别、置信度明确分离。

教程依据：Hello-Agents V1.0.3 第 4 章单 Agent 范式、第 7 章结构化输出，以及第 12 章安全指标
和固定案例评估原则。

当前行为：`IssueAnalyzer` 的系统提示定义五级风险，Fake LLM 输出经 `IssueAnalysis` 严格解析；
既有 Pydantic 门禁要求 `high/emergency` 必须人工复核且具有立即行动。当前没有真实模型、API 或
风险准确率评估。

验收条件：五个枚举值均能端到端往返；非法等级被拒绝；`undetermined` 不等于 `low`；类别、风险
和置信度分别判断；高风险咨询与紧急后勤组合合法；高风险/紧急输出缺少人工复核或立即行动时拒绝。

允许修改：风险系统提示、风险协议测试、领域词汇、架构和验证文档。

禁止修改：真实模型风险阈值、信息不足专项字段策略、高风险完整响应策略、API、前端、Function
Calling、工作流、RAG、图片上传和多智能体；禁止调用真实或付费模型。

测试命令：

```powershell
.\.venv\Scripts\python.exe -m pytest tests/test_analysis_risk_levels.py tests/test_analysis_categories.py tests/test_issue_analysis_output.py -q
powershell -ExecutionPolicy Bypass -File .\scripts\verify.ps1
```

人工确认点：安全、质量、管理和后勤代表共同复核五级定义、典型案例和升级阈值；后续使用真实模型
时，必须逐条记录高风险召回和漏报，不能以 Fake 协议测试替代专业验收。

## 五级定义

| 风险 | 定义 |
|---|---|
| `undetermined` | 现有文字不足以判断；不是低风险，不得乐观猜测。 |
| `low` | 未描述立即人身危险，影响有限，可通过普通说明、检查或常规处理跟进。 |
| `medium` | 需要及时现场核查或纠正，可能扩大或造成损失，但未描述严重伤害正在逼近。 |
| `high` | 存在可信的严重伤害、火灾、触电、坠落或结构风险，需要立即避险和专业复核。 |
| `emergency` | 危险正在发生或人员立即暴露、被困、冒烟、冒火花等，需要立刻启动现场应急处置。 |

## 判断边界

- 只依据用户明确提供的事实；证据不足时使用 `undetermined`，不能降为 `low`。
- 主类别表示业务归口，风险表示后果和紧迫度；咨询可以为高风险，后勤可以为紧急风险。
- `confidence` 表示对当前分析的把握程度，不是严重度；高置信度不能提高风险，低置信度也不能
  掩盖用户明确描述的紧急事实。
- `high/emergency` 的结构化输出必须包含至少一条立即行动并标记人工复核；完整路由、信息不足和
  高风险响应行为仍由后续专项任务继续收紧。

本任务证明五级协议和既有结构门禁可运行，不证明任何真实模型已经达到风险判断或高风险召回阈值。
