# 海之子 · 比赛试用版 v0.1.0-beta.3

适用于 Windows 10/11 64 位。下载 `SeaSon-v0.1.0-beta.3-windows-x64.zip`，完整解压后双击“海之子.exe”。
无需安装 Python、Node.js 或 Git；请勿下载下方自动生成的 Source code 作为运行包。

## 本次更新

- 修复切换话题后仍重复回答上一问题的会话上下文。
- 恢复“快速回复 / 深度思考”选择，默认快速回复；复杂问题可自行开启深度思考。
- 回答随生成逐步显示，发送后输入立即进入聊天区，并显示等待时间。
- 工单判断暂时不可用时保留完整聊天回答，可继续交流或手动填写工单。
- 有效的安全、质量、管理、后勤判断仍会打开对应申请，保存前须人工确认。
- 软件根目录更简洁，只保留启动程序、使用说明和内部资源文件夹。

更新时请先退出旧启动器，将新包解压到新文件夹，不要把两版文件混放；本机已保存的数据不变。

## 可以做什么

- 在同一个聊天入口进行日常交流和现场问题咨询。
- AI 判断需要跟进时，打开安全、质量、管理或后勤工单申请，人工确认后保存。
- 查看工单进展，进行派工、整改和复查。
- 添加图片证据、检索参考资料，保留必要的人工复核提醒。
- 使用原生模型设置窗口；客户界面只显示使用所需信息。

## 首次使用

软件默认未启用 AI。点击启动窗口的“模型设置”，填写自己的 DeepSeek 密钥和模型名称后启用。
模型服务需联网且可能收费，软件不包含密钥或赠送额度。已保存工单保存在本机，更新软件不会自动清空。

这是比赛非商业试用包，不是多人生产系统；AI 建议不能替代专业人员的现场判断。
程序尚未进行 Windows 代码签名，请只从可信来源下载，不要关闭系统安全防护。
仓库保持私有，下载需有访问权限；也可将 ZIP 直接上传比赛系统。
