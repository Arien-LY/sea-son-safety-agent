# 海之子 v0.1.0-beta.4 · Windows 比赛试用版

适用于 Windows 10/11 64位。下载 SeaSon-v0.1.0-beta.4-windows-x64.zip，完整解压后双击“海之子.exe”。无需安装 Python、Node.js 或 Git。

## 更新内容

- 基于2026-09-20最新主线：统一工单判断，回答下方手动生成草稿，人工核对、确认后保存。
- 聊天支持JPEG/PNG图片附件，保留最近聊天、置顶、删除和刷新恢复。
- 正式工单支持Word导出及二次确认后的本地删除。
- 包含规范检索、基础计算、公开搜索、网页读取和时间五项工具，以及后续真实验收发现的聊天问题修复。

## 使用与更新

先关闭旧版，将新包完整解压到新目录，不要混放版本。更新前备份 %LOCALAPPDATA%\SeaSon；升级不自动删除用户数据。
默认AI未启用，请在模型设置填写自己的DeepSeek密钥和模型；搜索另需Tavily密钥。真实服务可能收费，软件不附带密钥或额度。
聊天图片发送到配置的图片服务前，请自行遮挡隐私。公开案例数据不包含在包内。

本次打包使用离线测试，不重复调用付费模型；Tavily真实搜索仍待独立验收。适用于本机非商业试用，非多人生产系统；AI与计算结果不能替代现场专业判断。
