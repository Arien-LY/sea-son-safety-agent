海之子 · 安全质量工作台
Windows 10/11 64位比赛试用版

开始使用
1. 将压缩包完整解压到可写目录，不要直接在压缩包中运行。
2. 双击“海之子.exe”，稍等片刻，工作台会在默认浏览器打开。
3. 不需要安装 Python、Node.js 或 Git，也不需要输入命令。
4. 使用期间保留启动窗口；关闭启动窗口即停止服务。浏览器页面可以单独关闭再打开。

启用 AI
在启动窗口点击“模型设置”，填写自己的 DeepSeek 接口密钥、聊天模型和图片模型名称，勾选启用。
可另填 Tavily 搜索密钥，启用“联网工具”后按需搜索公开资料；搜索服务可能单独收费。
聊天框“工具”开关允许模型按需调用规范知识检索、基础计算、公开搜索、网页读取和日期时间。
规范检索与计算无需 Tavily 密钥；规范目录有限，必须明确适用地区并核对复核日期。计算仅支持基础四则，不作工程安全校核。
保存设置会重启工作台：成功聊天会保留，正在生成的回答会中断；请先保存工单申请。
密钥使用当前 Windows 用户的加密保护保存在本机，不会显示在聊天网页。
模型由服务商提供，需联网，使用可能收费。软件本身不附赠密钥或模型额度。
默认 AI 未启用，不会进行智能理解；此时仍可通过“提交工单”手工填写问题。

聊天和上报
在“新建聊天”里日常交流或描述问题；AI 判断需要跟进时，将打开对应类别的工单申请。
侧栏“最近聊天”可恢复成功问答；刷新会保留本标签页待重试的输入，但不会自动发送。
断线后手动重试可取回已经完成的相同请求；多标签发生版本冲突时请重新加载最新聊天。
联网回答下方可展开实际来源和工具结果。没有搜索密钥时会说明未配置；公开网页仍可按需读取。
不要将个人信息、内部项目资料或密钥用于公开搜索。来源须核对原文、日期及工程适用性。
请核对问题、风险、项目、区域等信息。确认并保存后才创建工单，不会自动派工或关闭。
在“历史工单”查看已保存记录，继续提交、派工、整改和复查。
高风险问题必须交由独立专业人员复核，AI 回答不能替代现场工程判断。
照片上传前请自行遮挡人脸、工牌和项目隐私；图片分析前另行确认外发与费用。

数据与更新
工单、图片、聊天历史和模型设置保存在当前用户的 %LOCALAPPDATA%\SeaSon 目录。
聊天记录是本地数据，备份中可能包含项目资料。当前最多200个会话，每个聊天最多50轮；无自动删除。
模型每次只读取最近最多12对问答且受字数预算限制；较早内容省略时页面会提示。
更新时先关闭软件，将新版本解压到一个新目录再启动；不要删除上述用户数据目录。
如需备份，请先退出软件，再将整个用户数据目录复制到安全位置。请勿把该目录作为软件包转发。
密钥只可由当前 Windows 用户解密，换电脑或换用户后需重新填写。
本机版仅供内部非商业试用，尚未核验身份、项目权限和人员资质，不适合公网部署或多人共享。

常见问题
没有打开页面：点击启动窗口的“打开工作台”。
启动失败：确认完整解压且资源文件没有被隔离；关闭后重试，或联系软件提供者。
AI 不回复：检查已启用 AI、网络、密钥、额度以及服务商实际支持的模型名称。
回答较慢：页面显示实际等待时间；停止等待不保证模型服务停止计算或计费。
回答正文随模型实际返回逐步显示，完成校验并保存后才成为历史；中断或校验失败会撤回临时正文。
搜索与网页读取有次数、长度及超时限制；暂不支持登录网页、重定向、PDF或需要运行脚本的页面。
本次开发增加的聊天/搜索功能尚未重新打包发布，旧版压缩包不包含这些更新。

这是未签名的试用软件。请只从可信的仓库下载并核对文件校验值；请勿关闭安全软件。
