- 《建设工程安全生产管理条例》：国务院令第393号公开文本，第27、28、29、31、32条。
- 《建设工程质量管理条例》：2019-04-23第二次修订公开文本，第29、30、32条。
- 释义不是逐字原文；来源 URL、发布者、版本及更新时间保留在 sources 中；条目记录条号、
  类别、范围、地区、关键词、复核日期和下次复核日期。
- 2026-08-30核对来源；内部复核截止日为2026-11-30，到当日自动停用本批引用。
  此截止日不是法规失效日期，入库核对也不是专业法律意见。
- 仅适用于中国内地建设工程候选检索；地区未知、港澳或其他境外项目不返回本批引用。
- 资料仅含公开法规短释义，不含个人信息、企业内部资料或商业标准全文。

## 维护

先核实公开来源与项目授权，再通过独立 Git 评审更新目录；不要直接修改生产数据。
复核时同步更新正文、来源版本、updated_on、reviewed_on、review_due_on。
撤回资料把 status 改为 withdrawn；记录 ID 不重用。每次检索重新读取目录，不保留陈旧缓存。
整体目录损坏、未知来源、非法域名或未授权材料会导致安全降级，不部分信任损坏目录。

检索只在本地进行，不下载网页、不调用模型/嵌入服务，不写入问题 Store；工具审计仅保留摘要。
机器契约与验收：[Phase 4 契约](../docs/phase4-knowledge-contract.md)。
